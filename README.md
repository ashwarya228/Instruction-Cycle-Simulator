✨ Instruction Cycle Simulator

Computer Organization and Architecture (COA) Project

A beautiful, interactive, software-based educational simulator that demonstrates how a CPU processes instructions step by step.

📌 About the Project

The Instruction Cycle Simulator helps engineering students understand the fundamental working of a processor through a simple, interactive interface.

It illustrates the four major stages of the instruction cycle:

1. Fetch – Retrieves the instruction from memory.
2. Decode – Interprets the instruction.
3. Execute – Performs the required operation.
4. Update – Updates the program counter and prepares for the next instruction.

🎯 Objectives

- Understand the internal working of a CPU.
- Learn the instruction cycle through practical simulation.
- Visualize register and memory changes.
- Connect theoretical COA concepts with software implementation.

⭐ Features

- Interactive instruction execution.
- Step-by-step Fetch, Decode, Execute and Update stages.
- Register and memory visualization.
- Support for basic instructions such as LOAD, STORE, ADD, SUB, MOV and HALT.
- Simple, student-friendly interface.
- Educational explanations for each stage.

🛠️ Technologies Used

- Python
- Streamlit for the graphical web interface

🎓 Expected Outcome

The project provides an interactive learning experience that helps students understand how a processor executes instructions and updates its internal state.
